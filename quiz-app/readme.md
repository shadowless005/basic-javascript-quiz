JavaScript Quiz

A simple interactive quiz application built with HTML, CSS, and Vanilla JavaScript. The app presents users with multiple-choice JavaScript questions, provides instant feedback on their answers, tracks their score, and allows them to restart the quiz.

Features:
Multiple-choice JavaScript quiz questions,
Instant feedback for correct and incorrect answers,
Highlights the correct answer after each selection,
Tracks the user's score throughout the quiz,
Displays the final score at the end,
"Play Again" option to restart the quiz,
Responsive and clean user interface;
